# Student Management System (Python)

A simple command-line based Student Management System built using Python and JSON for data storage.

---

## Features
- Add new students
- Remove existing students
- Search students by name
- Display all students
- Persistent storage using JSON file

---

## Tech Stack
- Python 3
- File Handling (JSON)
- Object-Oriented Programming (OOP)

---

## How to Run
```bash
python main.py
